四、The <a> 残留的处理（读了引擎源码才定的方案）
----------------------------------------------
引擎对最终 HTML 整串替换：块级正则处理不含内联 <a> 的块（整句键优先，146 条 The… 整句已翻好），
松散文本节点 #>([^<>]+)<# 处理被 <a> 截断的节点，键是 trim 后的节点文本。
→ 'The <a>…</a>' 里的 'The ' 是孤立节点，只能全局给一个值，无法按页区分 Le/La。
方案：'The ' -> 空（省略冠词），并给 5 条引用链接文字的法语值补正确冠词：
  PakFactory hexagon catalogue   -> Le catalogue hexagonal de PakFactory
  through-cut EVA holder         -> Le support EVA à découpe traversante
  SOS bag catalogue              -> Le catalogue de sacs SOS
  full-flap auto-bottom reference-> La référence fond automatique à rabats complets
  original box-style reference   -> La référence d'origine de style boîte
5 页逐一复验：The 消失，句首以带冠词的链接开头（Le catalogue/Le support/La référence），法语自然。

## 1. 两个 zip 的路径用了反斜杠（上线阻断）

`unzip -Z1 deploy/packrivo-quote.zip` 显示的是 `packrivo-quote\packrivo-quote.php`，主题包也一样。生产是 Linux，WordPress 用 PHP ZipArchive 解压时会把整串当成文件名，插件和主题都装不上。

- 用正斜杠重新打这两个包，例如 Python `zipfile`，arcname 用 `/`。目录结构不变：顶层就是 `packrivo-quote/`、`packrivo-home-v4/`。不包含 `demo/`。
- 验收：
  1. `unzip -Z1` 的输出里没有 `\`；
  2. 在 docker 的 Linux 容器里，用 PHP `ZipArchive` 把两个包分别解压到临时目录，列出文件树，和工作源逐字节对比；
  3. 用 `wp plugin install <zip> --force` 和 `wp theme install <zip> --force` 在**本地**装一次，站点正常，价格 4 组不变。

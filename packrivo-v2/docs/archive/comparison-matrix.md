## 汇总结论（跨条目，供后续迁移清单与规划者使用）

1. **最高优先级决策=业务定位冲突**：现站是"采购代理（8–15% 协调费 + 独立供应商制造）"，复刻站是"直营供应商（instant pricing）"。这一冲突贯穿 B01/B04/D05/D06/G02/F05——定价公式、流程区块、CTA 路径、联系方式时区是否可用，全部取决于先定业务模式。现站口径为现状，迁移默认以现站为准。
2. **可直接搬（两侧真实且一致）**：现站全部内容；复刻侧仅：设计令牌（globals.css @theme 全套）、组件/页面结构、英文文案骨架（18 SKU 字段、8 行业、10 指南、6 案例叙事结构）、定价公式与参数表（基准需换现站锚点）、SEO 模板组织方式、404/搜索字段映射、favicon.svg 与 BoxRender SVG。
3. **必须重做（复刻侧占位/虚构/侵权）**：全部位图（六竞品站抓取+14 组 MD5 重复）、认证徽标与编号（FSC C168842 等）、6 案例客户名与 metrics、3 条评价、经营数字（2,400+/94%/26wk/0 PVC/11 语种宣称）、价格基准（from/fromPrice 双口径）、联系方式时区（CET vs Shenzhen）、样品条款数字（29 USD 等）、setup/freight/payment 固定数字。
